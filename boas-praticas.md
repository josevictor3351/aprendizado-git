# Boas práticas no uso do GitHub

1. **Escrever mensagens de commit claras:** descrever o que foi alterado, como "Corrige cálculo do estoque".

2. **Usar branches para alterações:** criar uma branch para cada funcionalidade ou correção e abrir um pull request para revisar antes de integrar à main.

3. **Manter o README atualizado:** explicar o objetivo do projeto e como instalar e executar o código.
